# Implementation

## Step 1 — Initialize Repository

Goal:

Create the Git directory structure.

Command:

```bash
mygit init
```

Learned:

Git repositories are simply folders and files.

---

## Step 2 — Hash Files

Goal:

Generate SHA-1 hashes.

Command:

```bash
mygit hash hello.txt
```

Learned:

Git identifies content using hashes.

---

## Step 3 — Add Files

Goal:

Store objects and stage files.

Command:

```bash
mygit add hello.txt
```

Learned:

Git stores content in an object database.

---

## Step 4 — Commit Changes

Goal:

Create snapshots.

Command:

```bash
mygit commit "Initial Commit"
```

Learned:

Commits are snapshots, not collections of changes.

---

## Step 5 — View History

Goal:

Traverse commit history.

Command:

```bash
mygit log
```

Learned:

Git history is a linked list of commits.

---
